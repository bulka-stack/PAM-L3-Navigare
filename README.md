# StudyCards — флеш-карточки с интервальным повторением

Проект дисциплины PAM, тема **T13 StudyCards** (сложность: повышенная).
Автор: Andrii Kostin, группа TI-235. Преподаватель: унив. лектор Ionel Antohi.

**Этап L3 — навигация, формы и валидация.** Проект продолжает L2 (та же история git).
Навигация по адресам через `go_router`, постоянные вкладки, локально работающие формы.
Данные по-прежнему mock: список не растёт после submit — это контракт L3.

## Запуск

```bash
flutter pub get
flutter run            # эмулятор Android / телефон по USB
flutter run -d windows # desktop-окно Windows (если нет эмулятора)
flutter test
```

> Путь проекта содержит кириллицу (`Рабочий стол`). Для сборки Android и `flutter analyze`
> подключите папку как диск: `subst P: "C:\Users\<user>\OneDrive\Рабочий стол\PAM"`.

## Карта маршрутов (`lib/router.dart`)

| Адрес | Экран | Переход |
|---|---|---|
| `/login` | Вход (вне shell-а, без вкладок) | после входа — `go('/decks')` |
| `/decks` | Мои колоды — вкладка 1 | `goBranch` |
| `/decks/new` | Новая колода | `push` → `pop` |
| `/decks/review` | Сессия по всем колодам (на весь экран) | `push` |
| `/decks/:id` | Карточка колоды | `push` из списка |
| `/decks/:id/edit` | Редактирование колоды | `push` → `pop` |
| `/decks/:id/review` | Сессия по колоде (на весь экран) | `push` |
| `/decks/:id/cards/new` | Новая карточка | `push` → `pop` |
| `/decks/:id/cards/:cardId` | Редактирование карточки | `push` → `pop` |
| `/stats` | Статистика — вкладка 2 | `goBranch` |
| `/profile` | Профиль — вкладка 3; выход — `go('/login')` | `goBranch` |

## Формы и валидация

| Поле | Правило | Сообщение | Клавиатура |
|---|---|---|---|
| E-mail | непустой, формат `x@y.z` | «Введите e-mail» / «Неверный формат e-mail» | `emailAddress` |
| Пароль | ≥ 6 символов | «Пароль — минимум 6 символов» | `obscureText` |
| Название колоды | 3…60 символов | «Название колоды обязательно» / «Минимум 3 символа» | текст |
| Дисциплина | выбрана | «Выберите дисциплину» | `DropdownButtonFormField` |
| Лицевая сторона | непустая, ≤ 200 | «Лицевая сторона не может быть пустой» | многострочная |
| Обратная сторона | непустая, ≤ 500, ≠ лицевой | «Обратная сторона не может быть пустой» / «Ответ не должен повторять вопрос» | многострочная |

Feedback: SnackBar после сохранения; диалоги подтверждения — выход из аккаунта,
удаление колоды и карточки, досрочное завершение сессии.
